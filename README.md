# SupervisiKabkot1300

Dashboard Pengawalan Cakupan & Kualitas Sensus Ekonomi 2026 (SE2026) BPS untuk **Kabupaten Lima Puluh Kota (1308)** dan **Kota Payakumbuh (1376)**.

## Fitur Utama

- 🏢 **Pemisahan Section Wilayah**: Navigasi khusus antara Kota Payakumbuh (1376), Kabupaten Lima Puluh Kota (1308), dan Ringkasan & Perbandingan.
- 🛡️ **Pengawalan Kualitas**: Monitoring anomali keluarga & usaha, status assignment Fasih, kasus missing value, tim supervisi langsung, dan anggaran (RAB).
- 📋 **11 Poin Uraian Tugas**: Checklist interaktif 11 instruksi supervisi kualitas SE2026 dan tautan resmi SharePoint.
- 📊 **Tabel Rekap Prelist Sub SLS**: Paginasi 20 baris per halaman, pencarian instan, filter cascading Kecamatan & Desa, status capaian, dan modal 43 kolom detail.
- 📤 **Update Data via Excel (SheetJS)**: Fitur drag & drop file Excel `.xlsx` untuk memperbarui data pengawalan atau rekap prelist langsung di browser.
- ☁️ **Database Google Spreadsheet**: Terintegrasi dengan Google Apps Script (GAS) untuk sinkronisasi data cloud dua arah.
- 🎨 **Desain Modern**: Tipografi Plus Jakarta Sans, tema warna `#f79039`, Light Mode.

## Menjalankan Proyek

```bash
# Install dependensi
npm install

# Jalankan dev server
npm run dev

# Build untuk produksi
npm run build
```
